# Mobile usability refinement

## Goal
Keep the existing content, forms, tracking, and desktop presentation intact while making the shortened landing page easier and faster to scan on phones.

## Changes
- Review the complete page at the current phone width for overflow, awkward wrapping, excessive gaps, and cramped tap targets.
- Tighten mobile-only section spacing, heading margins, card gaps, and form spacing where this reduces unnecessary scrolling.
- Slightly reduce mobile-only type where needed, while keeping body copy readable and buttons/fields comfortably tappable.
- Clean up visible spacing artifacts in captions and labels that create poor wrapping or empty space.
- Preserve tablet/desktop layouts, all copy meaning, form behavior, tracking, and the sticky contact bar.

## Verification
- Check the page at phone and desktop widths for horizontal overflow, overlapping content, readable controls, and stable sticky actions.
- Check form validation and all primary quote, WhatsApp, and call actions.
- Confirm the preview reports a clean build with no runtime errors.
